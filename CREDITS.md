# Credits

All of these assets come from the **Step Quest** project. The licenses are as listed in Step Quest's own CREDITS.md.

## Characters
Built from Step Quest character sheets, then recolored and redrawn frame by frame (`tools/costume.py`) to match the Technomancers designs:
- **CraftPix.net** (free license, https://craftpix.net/file-licenses/): *Free Raider Sprite Sheets* (Scavenger → Augie; Outrider → Voidwalker; Marauder → Nanomancer, Saints enforcer, Tee), *Free Wizard Sprite Sheets* (Wandering Mage → Holoillusionist; Storm Mage → Dolores, Britt), *Free Ninja Sprite Sheets* (Kunoichi → Chronomancer), *Free Gangster Character Sprite Sheets* (Boss → Jester, Marquis, the Mantis crew, Dez, Chief Hale; Fixer → Calloway; Courier → Bernard, Frank, Seung, Carl, guards).
- Every character is one of these Step Quest sheets, recolored and edited frame by frame in `tools/build_sprites.py` + `tools/costume.py`.
